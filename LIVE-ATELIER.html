1-click fix — copy PowerShell command

Paste in PowerShell — it reads your token locally, builds the auth link, copies it, then open in Firefox (Chrome needs chrome://flags → Local Network Access → Disabled → Relaunch)

$tok=(Get-Content $env:USERPROFILE/.salla/config.json | ConvertFrom-Json).salla.access_token
$editor="https://s.salla.sa/themes/editor/draft-257077985?assets_url=http://localhost:8000&legacy=0&ws_port=8001"
$auth="https://s.salla.sa/auth/auto?access_token=$tok&source=partners&url="+[Uri]::EscapeDataString($editor)
Start-Process $auth
